# 🛡️ About Sudo Security X

**Sudo Security X** is an independent technical collective focused on **cybersecurity, AI security, open-source technology, privacy, vulnerability research, and emerging digital threats**.

We build tools, conduct experiments, investigate technical problems, publish research, and document what we learn.

Our work is organized into three primary archives:

```text
🛠 TOOLS
Security software, utilities, frameworks & experiments.

🔬 RESEARCH
Technical research, experiments, papers & analysis.

📝 WRITEUPS
Investigations, CTFs, technical analysis & lessons learned.
