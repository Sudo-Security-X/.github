# Privacy Policy

**Sudo Security X**

**Last Updated:** 2026-08-18

Sudo Security X respects the privacy of contributors, researchers, community members, and visitors.

This Privacy Policy explains how information may be handled when interacting with Sudo Security X repositories, websites, communication channels, and other official resources.

---

## 1. Scope

This policy applies to resources operated or directly managed by Sudo Security X, including:

- GitHub repositories
- Official website
- Official community channels
- Forms operated by Sudo Security X
- Research submission systems
- Other officially operated services

It does not automatically apply to third-party platforms used by Sudo Security X.

For example, GitHub and Telegram have their own privacy policies and data practices.

---

## 2. Information We May Receive

Depending on how you interact with Sudo Security X, we may receive information such as:

### Public Information

Information you intentionally make public, including:

- GitHub username
- Display name
- Public profile information
- Repository contributions
- Pull requests
- Issues
- Research authorship
- Public comments
- Public links

### Information You Voluntarily Provide

You may voluntarily provide information when:

- Contacting us
- Submitting research
- Opening a contribution
- Reporting a vulnerability
- Joining a project
- Participating in community activities

This may include a name, email address, username, or other information necessary to respond to your request.

---

## 3. Security Reports

Security researchers may provide sensitive information when reporting vulnerabilities.

Such information should be submitted through the appropriate private reporting mechanism whenever available.

We may process information necessary to:

- Investigate the vulnerability
- Reproduce the issue
- Communicate with the researcher
- Coordinate remediation
- Prepare a security advisory
- Provide appropriate attribution

We will avoid publicly disclosing sensitive information unnecessarily.

---

## 4. Research Submissions

If you voluntarily submit research, documentation, code, or other material, information associated with the submission may become publicly visible depending on the platform and publication process.

Before submitting sensitive information, consider whether it is necessary to include it.

Do not submit:

- Passwords
- Authentication tokens
- Private keys
- Personal identification documents
- Private addresses
- Unnecessary personal information
- Confidential third-party information

---

## 5. Public Contributions

GitHub contributions are generally public.

Depending on the platform, contributions may expose information such as:

- Username
- Commit history
- Pull requests
- Issues
- Comments
- Contribution dates
- Repository activity

Contributors should review their platform privacy settings before participating.

---

## 6. Website Information

The Sudo Security X website may collect limited technical information automatically through hosting providers, security systems, analytics tools, or other infrastructure.

Depending on the services used, this may include:

- IP address
- Browser type
- Device information
- Approximate location derived from IP
- Referring page
- Pages accessed
- Access timestamps

The exact information collected depends on the hosting and third-party services used by the website.

---

## 7. Cookies and Analytics

If the Sudo Security X website uses cookies, analytics, or similar technologies, the website should provide appropriate information about their use.

Where possible, we aim to minimize unnecessary tracking.

If analytics are introduced, the privacy implications should be reviewed before deployment.

---

## 8. Telegram and Third-Party Platforms

Sudo Security X may operate community channels on third-party platforms such as Telegram.

Those platforms operate independently and have their own:

- Privacy policies
- Data collection practices
- Terms of service
- Account systems

Sudo Security X does not control the information collected directly by these platforms.

Review the relevant platform's privacy policy before participating.

---

## 9. GitHub

Sudo Security X uses GitHub for source code, research, documentation, collaboration, and project management.

GitHub independently processes information according to its own policies.

Public contributions may remain publicly accessible even after a contributor leaves a project.

---

## 10. Information Sharing

Sudo Security X does not intentionally sell personal information.

Information may be shared when reasonably necessary to:

- Respond to a request
- Investigate a security issue
- Coordinate responsible disclosure
- Protect project infrastructure
- Comply with legal obligations
- Prevent abuse or serious security incidents

We aim to limit sharing to information that is reasonably necessary for the relevant purpose.

---

## 11. Public Disclosure

Information may become public when you intentionally publish it through public Sudo Security X or GitHub resources.

Examples include:

- Public research
- GitHub commits
- Pull requests
- Issues
- Writeups
- Public project documentation

Before publishing, contributors should ensure that they have the right to disclose the information.

---

## 12. Data Retention

Information may be retained for as long as reasonably necessary for the purpose for which it was collected.

Security reports may need to be retained longer for:

- Security history
- Vulnerability tracking
- Legal compliance
- Research records
- Incident documentation

Public GitHub contributions may remain available according to GitHub's systems and repository history.

---

## 13. Data Security

We take reasonable measures to protect information under our control.

These may include:

- Access controls
- Authentication protections
- Limited administrative access
- Secure communication where appropriate
- Credential protection
- Repository security controls

However, no online system can be guaranteed to be completely secure.

---

## 14. Children's Privacy

Sudo Security X does not intentionally collect personal information from children for purposes unrelated to our projects or community activities.

Users should follow the age requirements and terms of the third-party platforms they use to access Sudo Security X resources.

If you believe that personal information has been submitted to us inappropriately, contact the maintainers so the situation can be reviewed.

---

## 15. Third-Party Services

Sudo Security X may use third-party services for:

- Code hosting
- Website hosting
- Communication
- Analytics
- Email
- Project management
- Security monitoring

These services may process information independently under their own policies.

We recommend reviewing the privacy policies of services before using them.

---

## 16. Your Choices

Depending on the platform and circumstances, you may be able to:

- Avoid providing optional information
- Request clarification about information you submitted
- Request correction of information you directly provided
- Request deletion where reasonably possible
- Use a pseudonym for public contributions
- Choose whether to publicly associate your real name with research

Some information cannot reasonably be removed from public Git history or third-party platforms once published.

---

## 17. Changes to This Policy

This Privacy Policy may be updated as Sudo Security X introduces new services, communication channels, or infrastructure.

Changes will be reflected in this document.

The **Last Updated** date will be changed when significant updates are made.

---

## 18. Contact

For privacy-related questions, contact the Sudo Security X maintainers through an official communication channel.

For security vulnerabilities, follow:

`SECURITY.md`

For contributions, follow:

`CONTRIBUTING.md`

---

## 19. Transparency

Sudo Security X aims to collect as little personal information as reasonably necessary.

Our goal is simple:

> **Build technology without unnecessarily collecting information about the people using it.**
