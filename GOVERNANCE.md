# Governance

## Sudo Security X

Sudo Security X is an independent technical collective focused on building, researching, analyzing, and publishing work in cybersecurity, AI security, open-source technology, privacy, and related fields.

This document describes how the collective is organized and how decisions are made.

---

## 1. Core Principles

Sudo Security X operates around five principles:

### Build

We prioritize useful technical work over unnecessary hype.

### Research

We investigate technical problems through experimentation, analysis, and evidence.

### Document

We make our work understandable, reproducible, and accessible.

### Publish

We share useful knowledge and software whenever doing so is responsible.

### Learn

We encourage experimentation, criticism, iteration, and continuous improvement.
