# Security Policy

## Sudo Security X

Sudo Security X takes the security of its projects, infrastructure, and community seriously.

We encourage responsible security research and appreciate researchers who report vulnerabilities privately so that they can be investigated and addressed before public disclosure.

---

## Supported Projects

Security reports are currently accepted for:

- Official Sudo Security X repositories
- Official Sudo Security X websites
- Official Sudo Security X services
- Security issues affecting software maintained by Sudo Security X

Third-party projects are outside the scope of this policy.

---

## Reporting a Vulnerability

If you discover a security vulnerability affecting a Sudo Security X project or service, please report it privately rather than opening a public GitHub issue.

### Preferred Method

Use GitHub's **Private Vulnerability Reporting** feature when it is enabled for the affected repository.

If private reporting is unavailable, contact the Sudo Security X maintainers through an official communication channel and clearly indicate that the message contains a security report.

---
